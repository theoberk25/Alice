## Archive rules

- Archive only clearly superseded or completed material; age alone is insufficient.
- Preserve all original content, adding an archive notice and updating links.
- Record the date, reason, original path and active replacement in the move record.
- Keep active requirements, unresolved decisions, runnable instructions and unique
  integration guidance accessible in the active documentation tree.
- For mixed documents, extract only an explicitly obsolete section, preserve its
  complete text and heading in a dated archive file, and leave a link in its place.
  Keep existing section anchors reachable when other documents depend on them.
- Archived instructions and historical permissions are not current task authority.
- Never delete archived files as routine cleanup or duplicate them as active copies.
