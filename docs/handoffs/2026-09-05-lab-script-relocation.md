## Path contracts

- `common.repository_paths.repository_root()` resolves checkout data relative to
  the installed source anchor, independent of caller cwd and module depth.
- Runtime anomaly schemas use package resources in common.schemas.
- `scripts/lab/run.py COMMAND ...` launches from any cwd, including checkout paths
  with spaces. Existing root-level `python -m lab.*` and imports remain supported.
- Console HTML stays beside its owning module. Default artifacts stay under
  artifacts/enterprise-sim; explicit relative output arguments use caller cwd.
- Training manifests hash the new authoritative source paths. Historical reports
  retain their original paths/digests and are not regenerated by this migration.
- The local launch configuration now uses the scripts launcher. Its relative
  interpreter path still assumes launch from the repository root.
