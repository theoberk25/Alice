# Workstation scripts

Working directory: workstation/. Existing source:

- [desktop.mjs](../../workstation/scripts/desktop.mjs): native desktop launcher.
- [rust.mjs](../../workstation/scripts/rust.mjs): Rust toolchain launcher.
- [generate-contracts.ts](../../workstation/scripts/generate-contracts.ts): contract tooling.

Use [workstation commands](../../workstation/README.md). Package scripts and
location-relative paths require the original workstation/scripts/ placement.
New independent helpers may live here with an explicit working directory.
